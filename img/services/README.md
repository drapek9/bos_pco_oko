# Fotky ke kartám služeb

## BOS-PCO (`bos-pco.html`)

Cesty jsou v `style` u `.service-card__photo-slot` — např. `pco.jpg`, `fyzicka-ostraha.jpg`, …

## OKO (`oko.html`)

| Soubor | Služba |
|--------|--------|
| `oko-ezs.jpg` | Elektrická zabezpečovací signalizace EZS |
| `oko-cctv.jpg` | CCTV – kamerové systémy |
| `oko-eps.jpg` | Elektrická požární signalizace EPS |
| `oko-pristup.jpg` | Docházkové a přístupové systémy |

Formát může být i `.png` / `.webp` — upravte příponu v `url('…')` u příslušné karty v `oko.html`.

Dokud soubor chybí, zobrazí se tmavé výchozí pozadí karty.
