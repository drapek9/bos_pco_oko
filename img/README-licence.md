# Složka pro obrázky certifikátů a licencí

## Obrázky certifikátů

Umístěte sem obrázky certifikátů a licencí pro sekci "Licence a koncese" na stránce OKO:

- `licence-acs-line.jpg` (nebo .png) - Proškolení ACS-Line
- `licence-fbii.jpg` - Proškolení FBII
- `licence-euroalarm.jpg` - Proškolení Euroalarm
- `licence-paradox.jpg` - Proškolení Paradox Security
- `licence-esprit.jpg` - Proškolení Esprit
- `licence-honeywell.jpg` - Proškolení Honeywell Galaxy
- `licence-alphatel.jpg` - Proškolení Alphatel
- `licence-dominus.jpg` - Proškolení Dominus
- `licence-eps-lites.jpg` - Proškolení EPS Lites
- `certifikat-jablotron.jpg` - Certifikát Jablotron

## Formát obrázků

- Doporučený formát: JPG nebo PNG
- Rozlišení: minimálně 800x600px pro dobré zobrazení
- Velikost souboru: optimalizujte pro web (max 500KB na obrázek)

## Alternativní názvy

Pokud máte obrázky s jinými názvy, upravte cesty v souboru `oko.html` v sekci "Licence a koncese".
