# BOS-PCO & OKO - Webová stránka

Moderní, rychlá a SEO optimalizovaná webová stránka pro dvě propojené firmy:
- **BOS-PCO, s.r.o.** - Pult centrální ochrany, fyzická ostraha objektů, zabezpečení
- **OKO** (Ing. Vojtěch Jíra) - Montáže, servis, revize zabezpečovacích systémů

## Technologie

- **HTML5** - Sémantické značky
- **CSS3** - Moderní styly s CSS Grid a Flexbox
- **Vanilla JavaScript** - Bez frameworků, čistý JS

## Struktura souborů

```
/
├── index.html              # Homepage s rozcestníkem
├── bos-pco.html           # Sekce BOS-PCO
├── oko.html               # Sekce OKO
├── whistleblowing.html    # Whistleblowing stránka
├── css/
│   └── style.css          # Všechny styly
├── js/
│   └── main.js            # JavaScript pro interaktivitu
└── img/                   # Obrázky a loga
```

## Instalace a spuštění

1. Stažení souborů do webového adresáře
2. Otevření `index.html` v prohlížeči nebo nasazení na webový server
3. Pro lokální vývoj můžete použít jednoduchý HTTP server:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (s http-server)
   npx http-server
   ```

## Přidání log

1. Stáhněte loga z aktuálního webu (https://www.bos-pco.cz)
2. Umístěte je do složky `img/`:
   - `bos-pco-logo.png` (nebo .svg)
   - `oko-logo.png` (nebo .svg)
3. Upravte HTML soubory a přidejte `<img>` tagy s logy do headeru
